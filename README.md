# AM Webtech Experience

A premium, responsive redesign concept for AM Webtech's software quality assurance and testing brand.

## Stack
- Next.js App Router + TypeScript
- GSAP + ScrollTrigger
- Lenis smooth scrolling
- Lucide icons
- Responsive CSS with reduced-motion support

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Sections
Hero / QA console, capabilities, QA growth engine, interactive labs, delivery model, metrics and contact CTA.

## Notes
The project intentionally keeps the existing `SanFlash/PoheWalaa` repository untouched. Use this repository as the dedicated AM Webtech experience project.
